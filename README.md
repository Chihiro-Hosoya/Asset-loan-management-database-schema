# 資産管理リマインドアプリ

社内で利用するPCなどの資産を管理し、貸出・返却状況や返却期限を確認できるWebアプリケーションです。

## 📌 概要

現在の業務で行っている資産管理を題材に、業務上の課題をWebアプリケーションとして改善することを目的に個人開発しました。

資産の登録・編集・削除だけでなく、利用者への貸出、返却、返却期限を過ぎた資産の確認まで、一連の資産管理業務をWeb上で行えるようにしています。

---

## 🎯 開発目的

現在の業務で資産管理に携わる中で、

- 資産情報を一元管理したい
- 資産の貸出状況を把握しやすくしたい
- 返却期限を過ぎた資産を確認しやすくしたい

と考えたことをきっかけに開発しました。

また、JavaやSpring Bootを使用したWebアプリケーション開発を実践し、プログラミングの知識を深めることも目的としています。

## ✨ 主な機能

### 🔐 ログイン機能

Spring Securityを使用したログイン認証機能を実装しています。

- ユーザー名・パスワードによるログイン
- BCryptによるパスワードのハッシュ化
- 未認証ユーザーのアクセス制御

### 💻 資産管理機能

資産情報の登録・確認・編集・削除を行えます。

- 資産登録
- 資産一覧表示
- 資産情報編集
- 資産削除
- 資産ステータス管理

### 📤 資産貸出機能

登録されている利用者と資産を選択し、資産の貸出情報を登録できます。

- 利用者選択
- 資産選択
- 貸出日登録
- 返却期限登録
- 貸出中ステータスへの変更

### 📥 返却機能

貸出中の資産を返却し、返却日とステータスを更新できます。

### 🔔 返却期限リマインド機能

返却期限を過ぎている資産を一覧で確認できます。

返却期限と現在日付を比較し、期限を過ぎている貸出中の資産を表示します。

## 💡 工夫した点

### 1. 実際の業務を題材にした機能設計

現在の業務で扱っている資産管理を題材にすることで、単純なCRUDアプリではなく、

「登録 → 貸出 → 返却 → 期限超過確認」

という実際の業務フローを意識して設計しました。

### 2. 資産の状態を管理

資産のステータスを「貸出可能」「貸出中」などで管理し、現在の利用状況を確認できるようにしました。

### 3. 返却期限の確認を自動化

貸出情報の返却期限と現在日付を比較し、返却期限を過ぎた資産を一覧表示することで、確認作業を効率化できるようにしました。

### 4. Spring Securityによる認証

Spring Securityを使用してログイン認証とアクセス制御を実装しました。
